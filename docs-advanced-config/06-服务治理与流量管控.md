## 一、服务端限流

### 1. ExecuteLimit（并发执行数限制 - Provider 端）

#### 源码分析

```java
// dubbo-rpc/dubbo-rpc-api/.../filter/ExecuteLimitFilter.java
@Activate(group = CommonConstants.PROVIDER, value = EXECUTES_KEY)
public class ExecuteLimitFilter implements Filter, Filter.Listener {
    @Override
    public Result invoke(Invoker<?> invoker, Invocation invocation) throws RpcException {
        URL url = invoker.getUrl();
        String methodName = RpcUtils.getMethodName(invocation);
        int max = url.getMethodParameter(methodName, EXECUTES_KEY, 0);  // 默认 0 不限制
        if (!RpcStatus.beginCount(url, methodName, max)) {
            throw new RpcException(RpcException.LIMIT_EXCEEDED_EXCEPTION,
                "Failed to invoke method " + methodName + " cause: executes limit exceeded");
        }
        // ...
    }
}
```

**行为**：限制 Provider 端每个方法的最大并发执行数。超过限制直接抛异常拒绝。

#### Spring Boot 配置

```yaml
dubbo:
  provider:
    executes: 200  # 全局：每个方法最大并发 200
```

```java
@DubboService(executes = 100)  // 服务级别
public class OrderServiceImpl implements OrderService {
    // 所有方法最大并发 100
}

// 方法级别
@DubboService(methods = {
    @Method(name = "createOrder", executes = 50),   // 创建订单最大并发 50
    @Method(name = "queryOrder", executes = 200)    // 查询订单最大并发 200
})
public class OrderServiceImpl implements OrderService { }
```

### 2. TPS 限流（每秒事务数限制 - Provider 端）

#### 源码分析

```java
// dubbo-rpc/dubbo-rpc-api/.../filter/TpsLimitFilter.java
@Activate(group = CommonConstants.PROVIDER, value = TPS_LIMIT_RATE_KEY)
public class TpsLimitFilter implements Filter {
    private final TPSLimiter tpsLimiter = new DefaultTPSLimiter();

    @Override
    public Result invoke(Invoker<?> invoker, Invocation invocation) throws RpcException {
        if (!tpsLimiter.isAllowable(invoker.getUrl(), invocation)) {
            return AsyncRpcResult.newDefaultAsyncResult(
                new RpcException("exceed max service tps"), invocation);
        }
        return invoker.invoke(invocation);
    }
}
```

```java
// dubbo-rpc/dubbo-rpc-api/.../Constants.java
String TPS_LIMIT_RATE_KEY = "tps";              // TPS 限制值
String TPS_LIMIT_INTERVAL_KEY = "tps.interval"; // 统计间隔
long DEFAULT_TPS_LIMIT_INTERVAL = 60 * 1000;    // 默认 60 秒
```

**行为**：在指定时间窗口内限制最大调用次数。

#### Spring Boot 配置

```java
@DubboService(parameters = {"tps", "1000", "tps.interval", "1000"})
// 每 1000ms 内最多 1000 次调用（即 1000 TPS）
public class RateLimitedServiceImpl implements RateLimitedService { }
```

### 3. ActiveLimit（并发调用数限制 - Consumer 端）

#### 源码分析

```java
// dubbo-rpc/dubbo-rpc-api/.../filter/ActiveLimitFilter.java
@Activate(group = CONSUMER, value = ACTIVES_KEY)
public class ActiveLimitFilter implements Filter, Filter.Listener {
    @Override
    public Result invoke(Invoker<?> invoker, Invocation invocation) throws RpcException {
        int max = invoker.getUrl().getMethodParameter(methodName, ACTIVES_KEY, 0);
        if (!RpcStatus.beginCount(url, methodName, max)) {
            // 等待直到超时
            long timeout = invoker.getUrl().getMethodParameter(methodName, TIMEOUT_KEY, 0);
            synchronized (rpcStatus) {
                while (!RpcStatus.beginCount(url, methodName, max)) {
                    rpcStatus.wait(remain);
                    if (remain <= 0) {
                        throw new RpcException(LIMIT_EXCEEDED_EXCEPTION, "...");
                    }
                }
            }
        }
        return invoker.invoke(invocation);
    }
}
```

**行为**：限制 Consumer 端对每个方法的最大并发调用数。超过限制会等待（带超时），而不是直接拒绝。

#### Spring Boot 配置

```java
@DubboReference(actives = 10)  // 最大并发 10
private OrderService orderService;

@DubboReference(methods = {
    @Method(name = "heavyMethod", actives = 5, timeout = 10000)
})
private DataService dataService;
```

## 二、Token 鉴权

### 源码分析

```java
// dubbo-rpc/dubbo-rpc-api/.../filter/TokenFilter.java
@Activate(group = CommonConstants.PROVIDER, value = TOKEN_KEY)
public class TokenFilter implements Filter {
    @Override
    public Result invoke(Invoker<?> invoker, Invocation inv) throws RpcException {
        String token = invoker.getUrl().getParameter(TOKEN_KEY);
        if (ConfigUtils.isNotEmpty(token)) {
            String remoteToken = (String) inv.getObjectAttachmentWithoutConvert(TOKEN_KEY);
            if (!token.equals(remoteToken)) {
                throw new RpcException("Invalid token! Forbid invoke remote service...");
            }
        }
        return invoker.invoke(inv);
    }
}
```

**行为**：Provider 端配置 token 后，Consumer 必须携带正确的 token 才能调用。防止绕过注册中心直连。

### Spring Boot 配置

```yaml
dubbo:
  provider:
    token: true           # 随机生成 token（每次启动不同）
    # 或
    token: "my-secret-123"  # 固定 token
```

```java
@DubboService(token = "my-service-token")  // 服务级别 token
public class SecureServiceImpl implements SecureService { }
```

## 六、优雅停机（Graceful Shutdown）

### 源码分析

```java
// dubbo-common/.../config/ApplicationConfig.java
private String shutwait;  // 优雅停机等待时间

// dubbo-rpc/dubbo-rpc-api/.../AbstractGracefulShutdown.java
// ServiceConfig.java 中的优雅停机逻辑 (第 264-299 行):
// 1. 如果服务已空闲超过 shutdown time，直接 unexport
// 2. 如果空闲超过 2/3 shutdown time，等待剩余时间后 unexport
// 3. 否则等待 1/3 shutdown time，再检查是否空闲
```

### Spring Boot 配置

```yaml
dubbo:
  application:
    shutwait: 15000  # 优雅停机等待 15 秒
  registry:
    wait: 10000      # 注册中心注销等待时间
  # 或通过 JVM 参数
  # -Ddubbo.service.shutdown.wait=15000
```
